# CantForgetApp

**Daily personal task manager for Android, built with Kotlin and Jetpack Compose.**

A lightweight personal task manager designed for Android, focused on practicality, speed, and low resource usage. The app avoids unnecessary visual elements and background features, keeping storage requirements minimal and making it suitable for a wide range of Android devices. Compatible with **Android 7.0 (API 24) and later**.

## Features


- Create daily tasks
- Create shopping items
- Mark items as completed
- Edit existing entries
- Delete individual entries
- Clear completed items
- Local data storage
- Spanish and English interface
- No account required
- No cloud services
- No ads
- Works offline

## Overview

CantForgetApp explores a lightweight approach to personal task management on Android.

The application focuses on essential functionality while avoiding unnecessary dependencies, background services, and visual complexity.

Its goal is to provide a fast and straightforward way to keep track of everyday tasks and shopping items without requiring accounts, internet access, or additional services.

## Requirements

- Android 7.0 (API 24) or later
- No internet connection required after installation

## Technologies

- Kotlin
- Jetpack Compose
- Android SDK
- Android Studio

## Languages

- Spanish
- English

The interface automatically adapts to the language configured on the Android device.

## Installation

Download the APK and install it on a compatible Android device.

When installing, Android may ask you to allow installation from unknown sources for the application used to open the APK.
